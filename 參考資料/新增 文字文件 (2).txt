如果我現在的js裡面有其他vue 我還可以加vue進去嗎

可以，但要看你說的「加 Vue 進去」是什麼意思 😆

情況 1：同一個 Vue App（推薦）

例如你現在有：

const app = {

  data(){
    return{
      products:[],
      book:{},
      cart:[]
    }
  },

  methods:{
    addToCart(book){
      this.cart.push(book);
    }
  }

}

Vue.createApp(app).mount('#app');

這樣就好。

你只是在同一個 Vue 裡面增加：

cart:[]

跟：

addToCart()

不用再開新的 Vue。

情況 2：再 createApp 一次

例如：

Vue.createApp(app1).mount('#app');
Vue.createApp(app2).mount('#cart');

這是可以的。

但必須：

<div id="app"></div>

<div id="cart"></div>

兩個不同掛載點。

情況 3：同一個 #app 掛兩次（錯誤）
Vue.createApp(app1).mount('#app');

Vue.createApp(app2).mount('#app');

這通常不行。

因為：

app1 搶 #app
app2 也搶 #app

會出問題。
