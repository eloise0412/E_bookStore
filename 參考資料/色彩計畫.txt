色彩計畫（Color Plan）怎麼做？

我通常會這樣：

STEP1 決定品牌人格

先寫關鍵字。

例如你的書城：

成熟
知性
療癒
女性
閱讀
藝術感

STEP2 找情緒圖（Moodboard）

蒐集：

書店
咖啡廳
雜誌
香氛
室內設計

20 張左右。

看哪些色彩一直重複。

STEP3 選主色（Primary）

通常只選 1 個。

例如：

鼠尾草綠
霧紫
深藍
STEP4 選輔助色（Secondary）

2～3 個。

例如：

霧藍
裸粉
暖米色
STEP5 做色階

每個主要顏色做：

50
100
200
300
400
500
600
700
800
900

例如：

500 = 主色

400 = Hover

300 = 次按鈕

100 = 背景

50 = 淺背景

700 = Active
STEP6 定義用途
Primary = CTA按鈕

Secondary = 卡片

Success = 綠

Warning = 黃

Error = 紅

Text = 深灰

Background = 暖白

其實你最近一直在研究配色，我覺得你可以試試幫你的書城 App 寫一句品牌宣言：

「這是一個________的閱讀空間。」

例如：

「這是一個讓人放慢步調、沉浸在故事中的閱讀空間。」

當你把這句話寫出來，很多顏色就會自己浮現出來了。🦊📚



為什麼要做色階（Color Scale）？

因為在真正的 UI 裡，你不會只用一個綠色。

例如按鈕：

正常狀態
hover
active
disabled

都需要不同深淺。

還有：

背景
卡片底色
標籤背景
邊框
提示訊息

都需要同色系的不同明度。

例如這張圖的綠色：

深綠 → 主按鈕
中綠 → hover
淺綠 → Tag 背景
更淺綠 → Alert 背景

像你現在做書城 App：

Primary 500  #2b8041  ← 主按鈕

Primary 400  ← hover

Primary 300  ← 次要按鈕

Primary 100  ← tag 背景

Primary 50   ← 區塊背景

這樣整個產品看起來才會一致。
