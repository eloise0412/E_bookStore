下一章

nextChapter(){

    if(
        this.currentChapterIndex <
        this.chapters.length - 1
    ){

        this.currentChapterIndex++;

    }

    const chapter =
      this.chapters[
      this.currentChapterIndex
      ];

    this.$refs.audio.currentTime =
      chapter.start;

}

上一章

prevChapter(){

    if(this.currentChapterIndex > 0){

        this.currentChapterIndex--;

    }

    const chapter =
      this.chapters[
      this.currentChapterIndex
      ];

    this.$refs.audio.currentTime =
      chapter.start;

}

這裡的：

start: 0

意思是：

這個章節從音檔的第幾秒開始播放。

例如：

const chapters = [

    {
        title:'版權宣告',
        start:0
    },
版權宣告      從第 0 秒開始

當使用者點：

書籍介紹

時：

audio.currentTime = chapter.start;

實際上就是：

audio.currentTime = 31;

播放器會：

跳到 00:00:31 開始播放
-------

有 start:0, 為什麼還要 duration:'00:03:40'

duration

代表：

這個章節本身有多長

例如：

duration:'00:03:40'

表示：

這個章節長 3 分 40 秒

通常只是拿來顯示給使用者看：

書籍介紹                00:03:40

就像 Spotify：

歌曲名稱               03:25
